We present a refined, robust, and implementable two-stage heuristic algorithm for joint in-network aggregation (INA) placement and worker routing in distributed machine learning clusters, designed to minimize iteration makespan under strict hardware and capacity constraints. The approach maintains scalability by avoiding full-scale MILP solving while ensuring feasibility, correctness, and strong performance through a tightly coupled, constraint-aware design. The core innovation lies in a principled decoupling of placement and routing decisions, where placement is guided by a capacity-driven, topologically informed greedy selection, and routing is enforced via a flow-consistent, constraint-propagating assignment procedure that respects all system limits. We begin by identifying candidate INA switches from the network topology—edge and aggregation-level switches in FatTree, or leaf and spine switches in SpineLeaf—ensuring they are physically proximate to workers and capable of handling high-throughput aggregation. The INA placement phase proceeds greedily: at each step, we compute the potential reduction in the bottleneck rate across all jobs if a candidate switch were activated, based on a surrogate metric that combines the number of nearby workers, the total gradient volume they generate, and the expected alleviation of congestion on high-traffic links and the PS. This metric is computed efficiently using precomputed paths and link load indicators, avoiding expensive LP solves during selection. We select the switch with the highest marginal benefit, update the global load estimates, and repeat until exactly K switches are chosen, ensuring no switch is selected more than once and that placement remains within the budget.

Once the INA switches are fixed, we enter the routing phase, which is structured as a constrained assignment problem solved via a modified min-cost flow framework with explicit capacity enforcement. For each job, we model worker routing as a choice between two paths: direct to the PS or via one of the selected INA switches. The cost function for each possible assignment is defined as the negative of the effective rate gain, which accounts for both link utilization and switch load balance, penalizing assignments that push any link or switch beyond 85% of capacity. We initialize the assignment matrix with zeros and iteratively assign workers using a greedy, top-down approach: for each worker, we evaluate all valid aggregation points (selected INA switches and the PS), compute the resulting link and switch load, and select the option that maximizes the overall job rate while satisfying all capacity constraints. If no valid assignment exists for a worker, we fall back to direct PS routing only if it does not violate link or PS inflow limits. During assignment, we maintain a running total of per-link and per-switch loads, updating them dynamically to ensure feasibility. To enforce the "exclusivity" constraint, we ensure that each worker is assigned to exactly one aggregation point by setting the corresponding binary variables to one and all others to zero. We also explicitly enforce the flow conservation constraint: for every selected INA switch, the total incoming rate from workers must equal the outgoing rate to the PS, using a dual-rate variable structure where worker-to-INA rates are bounded by the sum of assigned flows, and INA-to-PS rates are constrained to be at least as large as any individual worker’s contribution. This prevents aggregation loss and ensures physical consistency.

To further improve solution quality, we incorporate a local search refinement loop that explores small perturbations: we consider swapping a worker’s assignment between an INA switch and the PS, or swapping INA placements between two switches, while re-evaluating the makespan using a lightweight LP solver. The evaluation step uses Gurobi to solve a reduced LP model that computes the maximum possible effective rate γ_j for each job under the fixed placement and routing decisions, enforcing all constraints including switch processing limits, link bandwidths, PS inflow sufficiency, and worker exclusivity. The LP model correctly includes binary indicators for assignments, big-M constraints to link rates to decisions, and flow conservation between workers, INA switches, and the PS. The objective is to maximize α = min_j (γ_j / m_j), which directly minimizes makespan t = 1/α. Only improvements in makespan are accepted, and the process continues until no further improvement is found. This iterative refinement ensures near-optimality without full MILP complexity. All constraints are enforced at every stage through explicit checks: worker assignment sum to one, INA budget limit, per-link and per-switch capacity limits, and single-hop routing. The algorithm is robust to edge cases: it checks for path existence before assignment, skips zero-capacity links, and handles disconnected topologies by defaulting to direct PS routing when no INA path is viable. The use of precomputed paths and efficient link-load lookup via `l_i` ensures scalability, even for large networks with thousands of workers and hundreds of switches. The final output is a feasible solution that satisfies all constraints, with a makespan that is competitive with full MILP solutions but computed in polynomial time, making it suitable for real-time deployment in production-scale machine learning clusters.
