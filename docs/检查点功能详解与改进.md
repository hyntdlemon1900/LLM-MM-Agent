## 1. 检查点功能概述

### 什么是 LangGraph 检查点？

LangGraph 的检查点（Checkpoint）是一个**持久化机制**，用于：

1. **保存工作流状态** - 在每个节点执行后自动保存完整的 state
2. **恢复执行** - 从任意检查点恢复工作流继续执行
3. **时间旅行** - 回溯到历史状态，重新执行部分流程
4. **调试追踪** - 查看每个步骤的输入输出

### 核心价值

```
长时间运行的工作流（如您的代码生成）：
- 运行时间：10-30 分钟
- 成本：大量 LLM API 调用
- 风险：网络中断、进程崩溃、错误重试

✅ 有检查点：从中断点恢复，节省时间和成本
❌ 无检查点：必须从头开始，浪费资源
```

### 2.2 问题分析

#### ❌ 问题 1: 参数命名错误
```python
parser.add_argument('--checkpoint', action='store_false', help='Enable checkpoints')
#                                           ^^^^^^^^^^^^
# store_false 意味着：
# --checkpoint → False (禁用)
# 不加参数 → True (启用)
# 这与 help 提示相反！
```

#### ❌ 问题 2: 配置文件缺失
```yaml
# config.yaml 中没有：
enable_checkpoints: true
checkpoint_path: "./checkpoints/llmina.db"
```

#### ❌ 问题 3: 无法恢复执行
```python
# 只调用了 invoke()，没有提供 thread_id 和恢复机制
final_state = workflow.invoke(initial_state)
# 应该是：
final_state = workflow.invoke(
    initial_state,
    config={"configurable": {"thread_id": "unique-run-id"}}
)
```

#### ❌ 问题 4: 没有检查点管理功能
- 无法列出历史检查点
- 无法查看某个检查点的状态
- 无法从指定检查点恢复
- 无法清理旧检查点

#### ⚠️ 问题 5: MemorySaver 作为默认
```python
else:
    checkpointer = MemorySaver()
```
MemorySaver 是内存存储，进程结束就丢失，不适合生产环境。

### 存储位置

#### SqliteSaver (推荐)
```
checkpoints/llmina.db
├── checkpoints 表
│   ├── thread_id (索引)
│   ├── checkpoint_ns
│   ├── checkpoint_id (主键)
│   ├── parent_checkpoint_id
│   ├── checkpoint (BLOB，序列化的状态)
│   └── metadata (JSON)
└── writes 表
    └── 每个节点的写入记录
```

#### MemorySaver (不推荐生产)
```python
# 存储在内存中的字典
{
    "thread-id-1": [checkpoint1, checkpoint2, ...],
    "thread-id-2": [checkpoint1, checkpoint2, ...]
}
# 进程结束即丢失
```

def main():
    parser = argparse.ArgumentParser(description='LLM Solver with Checkpoint Support')
    
    # 基础参数
    parser.add_argument('--task', type=str, default='LLMINA')
    parser.add_argument('--no-eval', action='store_true', help='Disable evaluation')
    
    # 检查点参数

                       help='Disable checkpoints (overrides config)')

    checkpoint_config = config.get('checkpoint', {})

    # 初始化 LLM
    llm = LLM(
        model_name=config.get('model_name'),
        key=config.get('api_key'),
        api_base=config.get('api_base')
    )
    
    # 构建工作流
    workflow = build_workflow(
        enable_checkpoints=enable_checkpoints,
        checkpoint_path=checkpoint_config.get('path'),
        enable_evaluation=not args.no_eval
    )
    
    # 生成或使用 thread_id
    if args.resume:
        thread_id = args.resume
        print(f"\n{'='*80}")
        print(f"Resuming from checkpoint: {thread_id}")
        print(f"{'='*80}\n")
    else:
        thread_id = f"llmina-{args.task}-{timestamp}"
        if enable_checkpoints:

            print(f"Thread ID: {thread_id}")

        llm=llm,
        config=config,
        task_name=args.task,
        output_dir=str(output_dir)

        print(f"Errors: {len(errors)}")

            print(f"Resume with: python main_langgraph.py --resume {thread_id}")
        print(f"{'='*80}\n")

    except Exception as e:
        print(f"\n{'='*80}")
        print(f"✗ Error: {e}")
        print(f"{'='*80}")
        if enable_checkpoints:
            print(f"Progress saved to checkpoint: {thread_id}")
            print(f"Resume with: python main_langgraph.py --resume {thread_id}")

### 6.3 增强 graph.py

```python
def build_workflow(
    enable_checkpoints: bool = False,
    checkpoint_path: Optional[str] = None,
    enable_evaluation: bool = True
):
    """
    构建工作流
    
    Args:
        enable_checkpoints: 是否启用检查点
        checkpoint_path: 检查点数据库路径（SQLite）
        enable_evaluation: 是否启用评估节点
    """
    # 创建图
    workflow = StateGraph(AgentState)
    
    # 添加节点
    workflow.add_node("load_problem", load_problem_node)
    workflow.add_node("generate_heuristic_template", generate_heuristic_template_node)
    workflow.add_node("heuristic_architect", heuristic_architect_node)
    workflow.add_node("generate_function", function_code_generator_node)
    workflow.add_node("integrate", code_integration_node)
    
    if enable_evaluation:
        workflow.add_node("evaluate", heuristic_evaluation_node)
    
    # 添加边
    workflow.add_edge(START, "load_problem")
    workflow.add_edge("load_problem", "generate_heuristic_template")
    workflow.add_edge("generate_heuristic_template", "heuristic_architect")
    
    # 条件边 - 函数生成循环
    def should_continue_generating(state: AgentState) -> str:
        next_action = state.get('next_action', 'integrate')
        return 'generate_function' if next_action == 'generate_next_function' else 'integrate'
    
    workflow.add_conditional_edges(
        "heuristic_architect",
        should_continue_generating,
        {'generate_function': 'generate_function', 'integrate': 'integrate'}
    )
    
    workflow.add_conditional_edges(
        "generate_function",
        should_continue_generating,
        {'generate_function': 'generate_function', 'integrate': 'integrate'}
    )
    
    # 集成后的路由
    if enable_evaluation:
        workflow.add_edge("integrate", "evaluate")
        workflow.add_edge("evaluate", END)
    else:
        workflow.add_edge("integrate", END)
    
    # 编译工作流
    if enable_checkpoints:
        if checkpoint_path:
            # 使用 SQLite 持久化存储（推荐）
            checkpoint_db = Path(checkpoint_path)
            checkpoint_db.parent.mkdir(parents=True, exist_ok=True)
            checkpointer = SqliteSaver.from_conn_string(str(checkpoint_db))
            print(f"[Checkpoint] Using SQLite: {checkpoint_db}")
        else:
            # 使用内存存储（不推荐生产环境）
            checkpointer = MemorySaver()
            print(f"[Checkpoint] Using MemorySaver (not persistent)")
        
        return workflow.compile(checkpointer=checkpointer)
    else:
        return workflow.compile()
```
